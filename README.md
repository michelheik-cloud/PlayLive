# PlayLive

PlayLive is an early static prototype for a live-experience platform focused on creators, communities, and interactive events.

## Current scope

- Responsive landing page in Portuguese.
- Initial product positioning and feature sections.
- Lightweight email signup interaction without backend persistence.

## Getting started

Run the local static server:

```bash
npm start
```

Then open <http://localhost:4173>.

## Checks

Validate the JavaScript syntax with:

```bash
npm run check
```
